# 任务：给一台新装的 Hermes 做初始化（记忆整理 + 避坑知识 + 使用说明）

> 这份来自一位 Hermes 老用户（他的 AI 助理）。随附的 `skills-必装/` 和 `skills-按环境选装/` 是同一批文件的一部分，一并接收后按下面执行。

## 优先级说明（全文按这个读）

- **★ 建议照做** —— 后面写了理由，跟着做通常省事
- **☆ 看情况** —— 按机主和环境的实际情况自己判断
- **⚠ 不建议** —— 做了通常会有麻烦，也写了为什么

（这份是建议清单，不是硬规矩。你的环境和机主的情况可能不一样，判断权在你。）

## 0. 背景与角色

这台电脑刚装好 Hermes。机主是刚开始用 AI 智能体的人，技术水平未知——先用第 1 步自检 + 第 2 步采访搞清楚。

- ★ 输出用**中文**（除非机主用别的语言；跟着机主的语言走就行）
- ★ **说话直接、少术语**，一次只让机主做一件事：她第一次用，信息一多容易懵
- ★ 机主可能就在旁边看着。每步做完先说一句结果，再进下一步
- ★ **不确定就问机主**：编出来的信息会写进记忆文件，以后一直错下去
- ☆ 机主如果中途问别的（"你能帮我做 XX 吗"），先简短回应，再回到初始化流程

## 1. 总目标（顺序大致这样，可以按情况调整）

1. 环境自检 → 2. 采访机主、建立初始记忆 → 3. 安装技能 → 4. 建每周自动整理任务 → 5. 本地实测 → 6. 写一页使用说明

☆ 开工前可以先花两分钟把随附每份 `SKILL.md` 扫一遍，知道自己在装什么。

## 2. 第 1 步：环境自检（★ 建议先做，几分钟）

逐条跑一下，顺手记下结果：

- Hermes 版本：`hermes --version`
- **配置目录**：Windows 是 `%LOCALAPPDATA%\hermes`，macOS / Linux 是 `~/.hermes`——确认你这台的实际路径
- **模型可用性**：跑一个极小验证（让机主随便问一句，或做一次最小工具调用），确认能返回
- ★ **默认模型和 key 是不是一对**：`hermes config get model.default` 看模型名，和 `.env` 里的 key 对一下厂商。不匹配的话，聊天可能正常（你手动选了模型），但**所有无人值守的运行**——定时任务、后台记忆审查、`hermes chat -q`——都在静默失败。新装机器很常见（向导写的推荐默认模型 + 后来只补了别家的 key）
- **系统与形态**：Windows / macOS / Linux；桌面版 / CLI
- **网络**：能不能正常访问 GitHub / PyPI（判断不了就直接问机主是不是在中国大陆）
- **定时任务**：`hermes cron list` 能否正常返回（Windows 上这条命令有时会卡住，记下原文就行，不代表坏了）
- 技能目录位置、现有技能数量

★ 把结果汇总成几行给机主看一眼，再往下走。

## 3. 第 2 步：采访机主 + 建立初始记忆（★）

**一次把问题问完比较省事**（分好几轮问，机主容易烦）。机主不想答的可以跳过，没答的先留空：

1. 怎么称呼你？这台电脑叫什么名字？
2. 你是做什么的？（学生：学校 / 专业 / 年级；工作：岗位 / 行业）
3. 平时最想让 AI 帮你做什么？
4. 喜欢什么样的回答风格？（简洁还是详细；要不要分步骤；要不要先给结论）
5. 你用笔记软件吗？（Obsidian / Notion / OneNote / 其他 / 不用）
6. 一般什么时候用电脑？电脑会关机或休眠吗？（这个影响第 4 步定时任务定在什么时间）
7. 有没有"绝对不要动"的文件夹或事情？
8. 还有没有特别想要的功能？（可选）

然后按 `hermes-memory-strategy` skill 的格式规则写两个文件：

- `<HERMES_HOME>/memories/USER.md`：机主画像与偏好（每条 ≤3 行）
- `<HERMES_HOME>/memories/MEMORY.md`：本机稳定事实 + 技能指针

★ **只写机主真说过的**（编的会一直留在记忆里）。☆ 写完可以念一遍给她听，顺便问要不要改。

## 4. 第 3 步：安装技能

- ★ **`skills-必装/` 建议全装**：每个目录整体复制到 `<HERMES_HOME>/skills/`
- ☆ **`skills-按环境选装/` 按自检结果挑**：
  - `windows-hermes-cron` ← Windows 才需要
  - `china-network-setup` ← 中国大陆网络环境才需要
  - `math-pdf-extraction` ← 会处理中文试卷 / 习题 PDF 才需要
  - 拿不准就问机主
- ★ **装之前查一下重**：遇到同名/同类技能，建议**不要直接覆盖**——先和自带的比一比，自带版本更新更全就用自带的，跟机主说一句原因
- ☆ 装完用 `skill_view` 逐个确认能读到，输出"技能名 + 一句话说明"的清单
- ☆ `hermes-known-issues` 里的坑是别处的经验，**不代表这台机器一定会遇到**；真遇到时再逐条核对

## 5. 第 4 步：建每周自动整理任务（★ 这是这套东西的核心）

- ★ 按 `memory-auto-cleanup-workflow` skill 建定时任务；☆ 时间默认周日 20:00，按第 2 步问到的习惯调整（关机就不跑，挑她在用电脑的时间）
- ★ cron 的 prompt **要自包含**：定时任务是独立会话，没上下文，写到的东西它才知道
- ☆ 建完 `hermes cron list` 看一眼 next run 时间对不对

★ 顺便告诉机主三件事（她不知道的话会以为"自动的"是万能的）：

1. 电脑关机 / 睡眠时任务不跑，**也不补跑**
2. 想立刻整理就说「**整理记忆**」，不用等周日
3. 每周任务是静默的，不弹通知

## 6. 第 5 步：本地实测（★ 建议至少手动跑一次）

- ★ 手动跑一次整理检查：读两个记忆文件，算出**字符数 / 使用率 / 每条行数 / 悬空指针**
- ★ 新装环境很可能一开始就是"无需清理"——**这也是有效结果**，照实说
- ★ 建议把实际数字和 `hermes cron list` 的输出贴给机主：她看不到你后台做了什么，没有输出的话她说"完成了"你也没法核对

## 7. 第 6 步：给机主一页使用说明（☆ 时间够就做，挺有用）

写成一个 md 文件放桌面（文件名用 ASCII，如 `hermes-usage.md`），用系统默认方式打开（Windows：`explorer.exe "<完整路径>"`；macOS：`open`；Linux：`xdg-open`）。内容建议：

1. **它能做什么**：陪聊、查资料；读写文档（Word / Excel / PPT / PDF）；扫描件转文字；整理文件；定时任务（每天 / 每周自动干活）；以后写代码、做小工具
2. **它记得什么**：你的偏好和电脑上的稳定事实（两个记忆文件）；重复做的事可以沉淀成"技能"
3. **怎么用最有效**：直接说人话；重要偏好加一句「**记住这个**」；说「**整理记忆**」让它整理；说「**把这件事做成技能**」，下次它就会自动这么做
4. **注意事项**：会消耗 API 额度；破坏性操作会先问你；重要文件自己先备份；它会犯错，关键内容自己核对一遍
5. **出问题怎么办**：让它查 `hermes-known-issues`；重启 Hermes；还不行就找帮忙装的人

## 8. 通用建议（★ 这几条建议尽量守）

- ★ 每一步先做完、给结果、再下一步（别一口气全做完最后才汇报）
- ★ **改配置、删文件、动机主的东西之前，先问一句**：这类操作不可逆，问一句成本很低
- ★ 不确定就问机主，或查文件核实——**别编**
- ★ 说"验证通过"时**带上真实输出**：不是规矩，是没输出的验证你自己也没法确认，机主更没法
- ☆ 机主明显不关心技术细节时，少报中间过程，直接说结果
