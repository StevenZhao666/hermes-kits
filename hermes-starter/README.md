# Hermes Starter

新装 Hermes 后的一套底座：记忆整理、避坑知识、文档处理，外加三个按环境选装的技能。

## 包含

必装（5 个）

- `hermes-known-issues` —— 常见坑与补救方案
- `hermes-memory-strategy` —— 记忆文件的结构与写法
- `memory-auto-cleanup-workflow` —— 每周自动整理记忆
- `memory-cleanup` —— 手动整理口令
- `ocr-and-documents` —— PDF / 扫描件文字提取

按环境选装（3 个）

- `china-network-setup` —— 国内网络下的镜像与下载
- `windows-hermes-cron` —— Windows 定时任务
- `math-pdf-extraction` —— 中文试卷 / 习题 PDF

## 安装

解压后把 `skills-必装/` 与 `skills-按环境选装/` 放进 Hermes 的 `skills/` 目录；或按 `提示词.md` 走完整初始化：环境自检 → 了解使用者 → 装技能 → 建每周整理任务 → 本地实测 → 写一页使用说明。
