# 一键网络优化

改三处 Windows 无线网卡设置，跑前跑后测速对比；可一键还原。

## 文件
- `optimize-network.bat` —— 双击运行（自动请求管理员权限）
- `restore-network.bat` —— 还原，读同目录的 `_原始设置.json`

## 它做什么
1. 无线网卡「首选频带」→ 5GHz（驱动支持才有）
2. 取消「允许计算机关闭此设备以节约电源」
3. 无线适配器节能模式 → 最高性能

## 依赖
Windows 10 / 11，系统自带 PowerShell 5.1。

## 注意
- 重启网卡时会断网十几秒
- 改之前自动备份到 `_原始设置.json`，日志写 `优化日志.txt`
- 不写死中英文属性名，按驱动 NDI 枚举定位网卡
