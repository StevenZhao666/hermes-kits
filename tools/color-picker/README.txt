ColorPicker —— 取色器（给色弱用户的用数字代替眼睛的小工具）
================================================================

【怎么用】
1. 双击桌面上的 ColorPicker 图标（或双击本文件夹里的 ColorPicker.ahk）
   启动后没有什么窗口，脚本在后台待命。
2. 按 Ctrl + Alt + C 开始取色。
3. 鼠标移到你要取色的地方（比如作业里那个色块），
   旁边的提示框会实时显示光标下那个像素的 HEX 和 RGB。
4. 左键单击 = 把 HEX 复制到剪贴板（形如 #800000），然后结束取色。
   右键或 Esc = 取消。

【为什么这样能解决色弱问题】
颜色判断题的答案都是十六进制码（#RRGGBB）。你不需要辨认颜色，
只要把取到的 HEX 字符串跟下拉框里的选项逐个字符比对即可 ——
#800000 对上 #800000 就行，全程用不到眼睛辨色。

【出问题时】
· 按 Ctrl+Alt+C 没反应：把 ColorPicker.ahk 拖到
  AutoHotkey v2 安装目录下的 AutoHotkey64.exe 上重新启动一次。
· 想换热键：用记事本打开 ColorPicker.ahk，
  改第 15 行的 PICK_KEY（^ = Ctrl，! = Alt，+ = Shift，# = Win）。
· 想让它开机自动待命：把桌面图标的快捷方式复制一份到
  Win+R 输入 shell:startup 打开的文件夹里。

【文件位置】
脚本：本文件夹里的 ColorPicker.ahk
运行环境：AutoHotkey v2（官网下载安装，装完双击 .ahk 即可运行）
