# ColorPicker · 取色器

按 `Ctrl+Alt+C` 取光标下的颜色，实时显示 HEX / RGB；左键单击复制 HEX。

给不靠眼睛辨色的人用：拿到 `#800000` 这样的字符串，直接和选项逐字符比对。

## 依赖
AutoHotkey v2（仅 Windows）

## 用法
1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)
2. 双击 `ColorPicker.ahk`，后台待命
3. `Ctrl+Alt+C` 取色 → 左键复制 / 右键或 Esc 取消

## 限制
仅 Windows。改热键需编辑脚本第 15 行 `PICK_KEY`。
